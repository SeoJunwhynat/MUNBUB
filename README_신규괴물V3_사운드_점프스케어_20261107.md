# 맛춘범 백룸 괴물 v3 통합 — 2026-11-07

## 변경 사항

### 괴물 모델
- 사용자 제공 `spelling_monster_v3.glb` (스킨 메시 6개, 본 160개, 애니메이션 9개) 사용
- 기존 임시 모델은 GLB/Three.js가 불러와지지 않을 때만 사용하는 폴백으로 유지
- 커스텀 WebGL의 벽/바닥/천장 먼저 렌더 → **같은 캔버스, 같은 WebGL context + depth buffer**에 GLB 렌더. 별도의 모델 overlay canvas 없음
- 원래 괴물 AI, 충돌 판정, 멀티 SSE, 문제은행 및 열쇠/탈출 로직 변경 없음
- 모델 높이 2.90m, 천장 3.35m
- Idle / Patrol / Search / Notice / Chase / Attack 애니메이션 실제 상태와 연결. 기타 클립(Stun/Pivot/Transition)은 모델 내부에 유지하며, 현 게임 AI에 대응되는 이벤트는 아직 없음

| 상황 | 소리 | 방식 |

| 추격 시작 | 비명1.mp3 | 최초 감지 시 1회, Notice→Chase 동작 |

| 플레이어가 잡힘 | 비명1.mp3 | 앞의 추격 소리 중단, Attack 애니메이션+점프스케어, 이후 결과 화면 |

기존 카펫 걷는 소리, 형광등 노이즈, 거리별 저음, 음소거(V) 기능 유지.

### 실행
- Windows/macOS: 압축 해제 후 **전체 폴더가 있는 위치에서** `python -m http.server 8000`, 브라우저에서 `http://localhost:8000/backrooms/`
- 최종 Vercel 사이트는 GitHub 저장소 소스를 업데이트하여 배포 필요 (현재 자동 배포 **미실행**)
- Three.js 모듈 로딩에 인터넷 접속 필요: `cdn.jsdelivr.net` / 버전 `0.160.1`
- 단독 HTML을 파일 탐색기로 `file://` 열면 ESM과 GLB가 CORS 보안 때문에 동작하지 않을 수 있으니 로컬 서버 권장
- 협동 플레이 서버는 원본 `backrooms/server.js` 그대로 보존. 실제 2인 접속 테스트는 서버 연결 후 진행 필요
