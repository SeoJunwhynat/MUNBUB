# 맛춘범 (MUNBUB)

맞춤법과 사자성어 학습 및 퀴즈 게임 프로젝트입니다.

- 웹 진입점: `index.html`
- 서버 API: `api/`
- 이미지와 UI: `ui-assets/`
- 배경 음악: `assets/bgm/`
- 서버 공통 코드: `lib/`
- 테스트: `tests/`

기존 `whynat0517/MUNBUB` 저장소의 코드를 `SeoJunwhynat/MUNBUB`로 이전했습니다. 신규 저장소의 `main` 브랜치를 Vercel 배포 소스로 사용합니다.

배포: https://matchunbeom.vercel.app/
