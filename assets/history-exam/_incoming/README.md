## 등록 방법

1. 작업 브랜치 `migration/render-neon`의 이 폴더에서 **Add file → Upload files** 선택
2. **`history_exam_sources_186_20261110.zip` 파일 하나만 압축을 풀지 말고 업로드**
3. **Commit changes** 누르기
4. Render 자동배포 빌드 로그에서 `History exam source images: 186 installed, 0 awaiting, original PNG SHA256 verified` 확인

- 모든 PNG는 **원본 바이트 그대로** 보존합니다.
- 전체 목록과 원본 파일별 크기·SHA-256을 확인한 뒤 배포합니다.
- `assets/history-exam/catalog.json`과 `images/*.png`는 빌드 과정에서 자동 생성됩니다.
- ZIP이 아직 없으면 기본 퀴즈는 그대로 작동하고 이미지 문제는 일시적으로 제외됩니다.
