맛춘범 Render 전체 소스 — 분할 ZIP 안내

하나의 전체 프로젝트를 4개의 독립 ZIP으로 분할했습니다.
파일 크기 때문에 전체 ZIP 다운로드가 실패할 때 사용하세요.

1. PART_01.zip ~ PART_04.zip을 모두 다운로드합니다.
2. 같은 새 폴더를 하나 만들고, 네 ZIP을 모두 '동일 폴더'에 압축 해제하세요.
3. 각 ZIP의 내부 폴더 구조를 그대로 유지해야 합니다.
4. 네 ZIP의 내용이 합쳐져야 완전한 311개 파일 프로젝트가 됩니다.
5. GitHub 저장소의 migration/render-neon 브랜치를 선택한 후 프로젝트 루트에 업로드합니다.
   기존 파일과 겹치면 변경 내용을 비교하고 덮어쓰세요.
6. Render 서비스는 해당 브랜치의 푸시 후 자동 배포됩니다.

가장 편한 방법은 용량 28.6MB짜리 MATCHUNBEOM_FULL_RENDER.zip 한 개만 받는 것입니다.

주의: PART_01.zip 하나만 업로드하면 사이트가 정상 작동하지 않습니다.
