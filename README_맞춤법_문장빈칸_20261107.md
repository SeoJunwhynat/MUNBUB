# 백룸 맞춤법 단말기: 문장 빈칸형 업데이트 (2026-11-07)

## 주요 변경
- 맞춤법 문제은행 156개 전부 문장 속 빈칸( ___ ) 문제로 통일.
- 맞춤법 단말기는 문장을 즉시 보여 주고, 빈칸을 시각적으로 강조한 뒤 선택지에서 알맞은 표기를 고르게 변경.
- 일부 동사·표현 선택지를 문장과 자연스럽게 연결되도록 활용형으로 수정. 문항별 정답·해설 유지.
- 솔로 클라이언트 내장 문제은행 `backrooms/index.html` 및 협동 서버 `backrooms/bank.json` 동시 수정.
- 협동 서버 `backrooms/server.js`가 문제 문장 자체를 보내고 정답은 서버에서만 검사. 정답·해설은 제출 후에만 공개.
- 사자성어는 기존 의미→답 선택 방식 그대로 유지.
- 단말기당 3문제 × 8개 = 총 24문제, 오답 10초 잠금·정답 진행도 보존·협동 팀 진행도 공유는 변경 없음.
- 기존 스태미나 탈진, 백룸 음향과 추격/붙잡힘 오디오, 조명·노이즈, 기존 맛춘범 본체 코드 유지.

## 확인 결과
- `node --experimental-vm-modules --test tests/*.test.mjs`: 35개 테스트 통과.
- 실 브라우저(Chromium) PC 1280×720, 모바일 390×844: 문장 표시, 빈칸 강조, 선택지, 답 선택 및 1/3 진행 정상.
- 브라우저 테스트는 검사용 훅을 임시 HTML에 주입하여 수행; 배포 HTML과 ZIP에는 테스트 훅이 포함되지 않음.
- Vercel·Render에는 자동 배포하지 않았음. 협동 서버 업데이트 시 서버 파일도 함께 변경해야 동일한 문장 문제가 출제됨.
