# 맛춘범 백룸 — 단말기 3문제 / 사운드 / 화면 분위기 업데이트

기준 파일: `matchunbeom_backrooms_stamina_fixed_20261106_full.zip` (기존 발소리/스태미나 탈진·100% 회복 잠금 포함)

## 게임 규칙
- 단말기: 총 8개 (맞춤법 4개, 사자성어 4개)
- 단말기별로 3문제를 **맞혀야** 완료 (총 24개 정답 = 유형별 12개)
- 정답 1개 → `1/3`, 정답 2개 → `2/3`, 정답 3개 → `3/3` 완료 (초록 모니터)
- 중간에 닫았다가 돌아와도 이미 맞힌 문제의 진행도는 유지 (게임 세션 중)
- 오답이면 기존처럼 단말기 10초 잠금, **맞힌 문제 수는 유지**하고 다음에 새 문제로 재시도
- 유형별 단말기 4개 모두 `3/3` 완료해야 해당 열쇠 획득 가능
- 협동 플레이: 정답 검증 및 진행도 저장은 서버가 관리, 모든 플레이어에게 공유. 동시 응답으로 이미 바뀐 문제에 답하면 새로 열도록 안내
- 맵 목표와 화면 진행도: `0/12문제 · 0/4기` 형식, 단말기에 접근 시 `0/3` 등 현재 진도 표시
- 매번 새로운 플레이 시 진행 초기화. 브라우저 종료 후 복구되는 영구 저장은 구현하지 않았음.

## 사운드 및 화면
- 기존 카펫 발소리·형광등 웅웅거림·공기/노이즈를 유지
- 괴물과 가까워질수록 낮은 긴장음이 커지며, 멀어지면 자연스럽게 줄어듦
- 오래된 건물 삐걱거리는 소리가 드물게 나타남
- 단말기 열기, 정답/오답/3문제 완료, 탈진/스태미나 회복 사운드 추가
- 노란 빛 번짐, 미세한 필름 노이즈, 조명 간헐 깜빡임, 복도 원거리 안개, 바닥/벽 조명 톤 조정
- PC와 모바일 지원. `V`키와 상단 🔊 버튼으로 음소거, 기존 음소거 저장 유지
- OS의 모션 최소화 옵션 사용 시 오버레이 노이즈/깜빡임 애니메이션을 줄임
- 게임 사운드는 브라우저 정책상 **처음 게임 버튼/터치 이후** 재생됨

## 파일 및 실행
- `index.html`: 기존 맛춘범 메인(그대로 유지)
- `backrooms/index.html`: 수정된 백룸 게임
- `backrooms/server.js`: 협동 진행도(0~3)·정답 검증 업데이트
- `tests/backrooms-integration.test.mjs`, `tests/backrooms-audio.test.mjs`, `tests/backrooms-stamina.test.mjs`, `tests/backrooms-atmosphere-progress.test.mjs`: 자동 테스트
- 혼자 플레이: 제공하는 별도 HTML 파일을 브라우저로 열거나, 전체 ZIP에서 `backrooms/index.html`을 실행할 수 있음
- 협동 플레이: **전체 ZIP을 함께 배포**하고 맛춘범 로그인/서버가 실행 중이어야 함. 변경된 백룸 서버를 배포하지 않은 구버전 서버에는 새 진행도가 동작하지 않음.
- GitHub / Vercel 배포는 **수행하지 않음**. 현재 ZIP을 사이트 파일에 적용해야 실제 사이트에 반영됨.

## 확인한 결과
- 자동 테스트 `30/30` 통과 (Node.js 22, `node --experimental-vm-modules --test tests/*.test.mjs`)
- 브라우저 테스트: PC/모바일 화면 로딩, 솔로 1/3→2/3→3/3, 오답 후 진도 유지, 새 배경 노이즈 표시, 실행 오류 없음
- 브라우저 환경에서 실제 GPU WebGL 대신 호환 렌더러 사용. 기기별 WebGL 최종 색감·음향은 배포 전 실기기 확인 권장
