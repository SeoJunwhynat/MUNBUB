맛춘범 백룸 독립 3D 협동 게임 v3
=============================

이번 버전
- 솔로 플레이 (HTML 단독 실행 가능)
- 2~4인 멀티플레이: 방 코드, 대기실, 준비, 시작, 다른 플레이어 3D 표시
- 팀 공통 문제 8개, 맞춤법·사자성어 열쇠 2개, 탈출 조건 공유
- 서버가 괴물 추격과 정답/오답 및 단말기 10초 잠금을 관리
- 모바일 UI 13개 요소(조이스틱, 달리기, 조사, 지도, 인벤토리, 스태미나, 목표창,
  괴물 경고, 상단 메뉴, 조사 안내, 조준점, 알림, 팀 정보) 드래그/크기 변경
- 모바일 가로/세로 설정 별도 저장(같은 브라우저의 로컬 저장소 사용)
- 맞춤법 156문항, 사자성어 95문항 기본 문제은행 (총 251문항)

1. 솔로 모드
  index.html 파일을 브라우저에서 바로 열면 됩니다.
  ※ file://에서 멀티플레이는 동작하지 않습니다. 협동 플레이는 아래 서버 실행이 필요합니다.

2. 협동 플레이 준비 (Windows / macOS / Linux)
  - Node.js 18 이상을 설치합니다.
  - 이 ZIP을 모두 압축 해제합니다.
  - Windows: start_windows.bat을 더블클릭하거나 터미널에서 'node server.js'를 실행합니다.
  - macOS/Linux: 'sh start_mac_linux.sh' 또는 'node server.js'를 실행합니다.
  - 다른 라이브러리나 npm install이 필요 없습니다.
  - PC에서 http://localhost:8787 을 브라우저로 엽니다.

3. 휴대폰과 함께 플레이
  - 휴대폰과 서버 PC를 같은 Wi-Fi에 연결합니다.
  - PC의 사설 IP 주소를 확인합니다. (예: 192.168.0.12)
    Windows: ipconfig / macOS: 시스템 설정 > 네트워크
  - 휴대폰에서 http://192.168.0.12:8787 (예시 주소)을 엽니다.
  - PC에서 '함께 탐험하기' > '새 방 만들기'를 선택합니다.
  - 나타난 6자리 방 코드를 친구에게 보냅니다.
  - 친구가 '함께 탐험하기' > 방 코드 입력 > '코드로 입장'을 누릅니다.
  - 친구가 '준비 완료'를 누르면 방장이 '협동 탐험 시작'을 누릅니다.
  - 최대 4명, 최소 시작 인원 2명입니다.
  - 외부에서 접속하려면 별도의 HTTPS 서버에 이 Node 게임 서버를 배포해야 합니다.
  - PC 방화벽에서 TCP 8787 포트 접근 허용이 필요할 수 있습니다.

4. 모바일 UI 크기/위치 설정
  - 타이틀의 '모바일 조작 UI' 또는 플레이 중 상단 '⚙ 배치'를 누릅니다.
  - 목록에서 변경할 요소를 선택하고, 화면의 테두리 표시된 요소를 드래그합니다.
  - 크기 슬라이더로 원하는 크기를 설정합니다.
  - 저장하고 닫기를 누릅니다. 초기화 버튼으로 기본 배치 복원할 수 있습니다.
  - 가로 화면과 세로 화면 설정은 따로 저장됩니다.

5. 문제 및 협동 규칙
  - 단말기 8개(맞춤법 4개, 사자성어 4개)의 정답 진행은 팀 전체에 공유됩니다.
  - 오답이면 단말기가 10초간 붉게 잠기고, 다시 흰색으로 바뀐 후 다른 문제가 나옵니다.
  - 유형별 단말기 4개를 모두 풀고 해당 방에 있는 열쇠를 가져옵니다.
  - 열쇠 2개를 확보한 상태에서 출구를 조사하면 팀이 탈출합니다.
  - 괴물은 서버 기준 가장 가까운 생존 플레이어를 추적합니다.
  - 모든 플레이어가 잡히면 해당 방의 탐험은 끝납니다.

현재 프로토타입 제한 사항
  - 공용 온라인 호스팅/계정/초대 매칭/채팅 기능은 아직 제공하지 않습니다.
  - 서버를 닫으면 임시 방과 진행 내역이 초기화됩니다.
  - 단순 협동 게임 서버이며 상용 환경 수준의 인증·부정행위 방지는 포함되지 않았습니다.
  - 멀티는 반드시 같은 서버 주소로 접속해야 하며 HTML 단독 파일만으로는 지원하지 않습니다.
  - 실기기 모바일 브라우저/공용 인터넷 서버 장시간 부하 테스트는 아직 하지 않았습니다.

파일 구성
  index.html: 독립 게임(솔로 + 서버 연결용 클라이언트)
  server.js: Node 내장 http 기반 협동 서버 (외부 패키지 불필요)
  bank.json: 기존 맛춘범 기본 맞춤법 156개 + 사자성어 95개
  package.json: npm start 실행용 설정
  start_windows.bat, start_mac_linux.sh: 서버 실행 스크립트
  preview_*.png: 개발 중 UI 테스트 스크린샷
